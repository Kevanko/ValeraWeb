# ValeraWeb

Full-stack web application built with ASP.NET Core API and React frontend for authentication and data management.

## Overview

This repository contains a backend API, a frontend client, and a test project for a full-stack web application.

## Structure

- `ValeraApi` - ASP.NET Core backend
- `valera-frontend` - React frontend
- `ValeraApi.Tests` - backend test project

## Stack

C#, ASP.NET Core, React, SQLite, JWT authentication.

## Notes

This project is a good example of a multi-part academic web application with separate frontend and backend layers.
